# ✨ Bridal Service Website

A modern, elegant, and responsive **Bridal Service Website** designed to showcase professional bridal makeup and beauty services through a clean, premium, and visually engaging web experience.

🌐 **Live Website:** [suriva.indevs.in](https://suriva.indevs.in)

---

## 💍 About the Project

The **Bridal Service Website** is a frontend-focused website created for a bridal beauty service brand.

The website is designed around a premium bridal aesthetic, providing visitors with an attractive way to explore the services, understand the brand, and get in touch for bridal bookings and inquiries.

The primary focus of the project is **visual presentation, responsive design, smooth user experience, and professional branding**.

* 💄 Elegant bridal-focused design

## 🔧 Getting Started

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/ciperpy/Bridal-service-site.git
```

### 2. Open the project

```bash
cd Bridal-service-site
```

### 3. Run the website

Since this is a frontend website, you can simply open `index.html` in your browser.

For development, you can also use **VS Code Live Server** or another local development server.
